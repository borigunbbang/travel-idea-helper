# 여행 구상 도우미

여행 구상을 적으면 실제 자료를 조사해 **핵심 개념**을 제안하고, 고른 개념마다 **따져볼 쟁점과 근거가 있는 해설**을 만드는 앱입니다. 자료가 모자란 곳은 **자료 부족**으로 표시합니다.

> 2026-10-23 카드뉴스 에이전트를 이 앱으로 바꿨습니다(DECISIONS 44). 카드뉴스 코드와 확인 기록은 git 기록(커밋 `725cf53`까지)에 있습니다.
>
> **실행 결과 보기(카드 12장과 해설 문서): https://borigunbbang.github.io/travel-idea-helper/** — 앱으로 만든 결과물을 보여 주는 정적 페이지입니다. 앱 자체는 아래 '실행하기'대로 내 컴퓨터에서 켭니다.
>
> **과제 제출물 모음은 [submission/README.md](submission/README.md)** 에 있습니다: 정상 입력·자료 부족 입력 실행 화면과 산출물, 실패와 개선, 카드뉴스 완료 범위.
(원래 키트 안내는 `KIT_README.md`, 요구사항은 `PRD.md`, 결정 기록은 `DECISIONS.md`, API와 연결 방식은 `API_SPEC.md`)

> 기본 엔진은 **Claude CLI**(실제 웹 검색)입니다. 미리 `claude`가 설치·로그인되어 있어야 합니다(터미널에서 `claude`를 한 번 실행해 로그인).
> 화면만 확인하려면 모의 엔진으로 켭니다: `TRAVEL_ENGINE=mock .venv/bin/python -m app.main` — 이때 화면 상단에 "모의 데이터입니다"가 표시됩니다.
> 개념 제안에 약 2분, 해설에 약 3~6분 걸립니다.

## 실행하기 (처음 해 보는 사람용)

준비물: macOS, Python 3.10 이상. 터미널에서 `python3 --version`을 입력해 버전이 나오면 됩니다.

### 1. 터미널 열기
`⌘ + Space` → `터미널` 입력 → Enter.

### 2. 앱 폴더로 이동
터미널에 아래를 입력하고 Enter. 이후 명령은 모두 **이 폴더에서** 입력합니다.
```bash
cd ~/Documents/Aifel/card-news-workflow-kit
```
폴더를 다른 곳에 두었다면 그 경로로 바꿉니다. (Finder에서 폴더를 터미널 창으로 끌어다 놓으면 경로가 입력됩니다.)

### 3. 처음 한 번만: 실행 환경 만들기
```bash
python3 -m venv .venv
```
```bash
.venv/bin/pip install fastapi uvicorn pillow
```
두 번째 실행부터는 이 단계를 건너뜁니다.

### 4. 앱 켜기
```bash
.venv/bin/python -m app.main
```
아래처럼 나오면 켜진 것입니다. **이 터미널 창은 닫지 말고 그대로 둡니다.**
```
열기: http://127.0.0.1:8765
INFO:     Uvicorn running on http://127.0.0.1:8765 (Press CTRL+C to quit)
```
`포트 8765가 사용 중입니다`가 나오면 이미 켜져 있거나 다른 프로그램이 쓰는 중입니다. 다른 번호로 켭니다.
```bash
.venv/bin/python -m app.main 8766
```
이때 아래 브라우저 주소도 `8766`으로 바꿉니다.

### 5. 브라우저에서 열기
Chrome이나 Safari 주소창에 입력합니다.
```
http://127.0.0.1:8765
```
1. 여행 구상(예: `12월 말에 혼자 3박 4일. 따뜻하고 조용한 바닷가에서 많이 걷고 싶다. 인천 출발`)을 적고 **핵심 개념 제안 받기**
2. 위쪽에 구상에서 뽑은 조건과 **정하지 않음** 조건이 보입니다. 개념들이 **후보 지역 사진**과 함께 한 화면에 나옵니다(위키미디어 공용의 그 장소 분류에서 최근 컬러 사진을 차례로 받아 오므로 장소당 몇 초). 항목의 **자세히 보기 ›**를 누르면 큰 사진과 출처·부족한 자료를 보고 거기서 바로 고를 수 있습니다. 1~3개를 체크하고 **해설 만들기**. 해설 단계에서도 **후보 사진 한눈에 보기** 탭으로 다시 볼 수 있습니다
3. 시기·예산처럼 해설을 크게 바꾸는 조건이 없으면 질문이 나옵니다. 답하고 **답변 제출**
4. 해설이 **그림 카드**로 나옵니다. ‹ › 버튼, 키보드 ← →, 밀기, 아래 작은 카드로 넘겨 봅니다. 카드 옆에 그 쟁점의 **문제 · 판단 · 해설 · 근거(링크·종류·게시일) · 근거 수준**이 보입니다. 한 번에 글로 보려면 **전체 글로 보기**를 엽니다
   - 초록 **근거 충분**, 주황 **근거 일부**, 빨강 **자료 부족**. 앱이 실제 출처를 세어 AI 판단보다 낮출 수 있습니다
   - **⚠ 부족한 자료**에 무엇이 없는지, 왜 필요한지, 어디서 확인하면 되는지가 나옵니다. '(앱 점검)'은 앱이 찾은 것입니다
5. 고칠 쟁점은 체크하거나 요청에 `3번`처럼 적고 **고치기**. 부족한 자료가 있으면 **이 쟁점 자료 더 찾기**로 추가 검색합니다. 고른 쟁점만 새 버전이 됩니다
6. **최종 승인하고 내보내기** → **카드 전체 ZIP**(`travel-cards.zip`), 카드별 PNG, `guide.html`·`guide.md`(해설 문서), `sources.json`(근거·부족한 자료)을 내려받습니다
7. 승인 직후 앱이 내보낸 파일을 다시 열어 **누락·카드·자료 부족 표시·링크·날짜**를 점검합니다. **미확인**은 통과가 아니므로 '직접 확인할 것'을 봅니다(`check_report.md`)

시험할 때 실제 프로젝트를 건드리지 않으려면 다른 데이터 폴더로 켭니다: `TRAVEL_DATA=/tmp/travel-test .venv/bin/python -m app.main 8766`

주소 끝의 `#p_...`가 프로젝트 번호입니다. `#p_.../photos`는 후보 사진 모음, `#p_.../photos/k1`은 그 개념의 자세히 보기를 바로 엽니다. 새로고침하거나 이 주소를 다시 열어도 진행 상태가 그대로 남습니다. 새 구상은 왼쪽 **＋ 새 여행 구상**을 누릅니다.

### 6. 앱 끄기
앱을 켠 터미널 창을 클릭하고 `Control + C`를 누릅니다. 입력 대기 줄(`%`)이 다시 보이면 꺼진 것입니다.

터미널 창을 이미 닫아 버렸다면 새 터미널에서:
```bash
pkill -f app.main
```

### 기록 지우기
진행한 구상은 `data/travel/` 폴더에 저장됩니다. 앱을 끈 뒤 이 폴더를 휴지통으로 옮기면 처음 상태가 됩니다. (예전 카드뉴스 기록은 `data/app.db`, `data/projects/`에 그대로 있습니다.)

| 공용 분류 방식 | 통과(일부) | 15곳 중 7곳 받음: 희방사·제천 전경·아산·동래온천·웰리힐리파크 야경·동궁과 월지·안동 전경. 7곳은 429로 실패, 1곳은 사진 없음 |
| 사진 모음 → 자세히 보기 | 통과 | 항목을 누르면 자세히 보기, 이전/다음 개념, 고른 개념은 쟁점 목록에서 누르면 그 카드(4/12)로 이동 |

알려진 한계:
- **사진 정확도:** 장소 이름이 긴 경우 도시 문서 사진(예: '경북 영주 국립산림치유원' → 영주시)이 나온다. 그래서 어느 문서의 사진인지 함께 적는다.
- **사진 종류:** 장소의 공용 분류에서 점수로 고르므로 대표 풍경이 아닐 수 있다. 분류가 도시 단위면 도시 사진(예: 온양온천 → 아산 아파트 단지)이 나온다(DECISIONS 63).
- **위키미디어 제한(429):** 이 컴퓨터에서 오늘 시험을 많이 해 요청이 자주 막힌다. 내 구상 15곳 중 7곳이 막혀 실패했다. 시간이 지나 '못 받은 사진 다시 찾기'를 누른다.
