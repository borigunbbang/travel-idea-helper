# 카드뉴스 에이전트

주제를 입력하면 자료를 조사하고, 브라우저에서 후보를 고르고 질문에 답하며 카드뉴스를 만드는 앱입니다.
(원래 키트 안내는 `KIT_README.md`, 요구사항은 `PRD.md`, 결정 기록은 `DECISIONS.md`, API와 연결 방식은 `API_SPEC.md`)

> 기본 엔진은 **Claude CLI**(실제 웹 검색)입니다. 미리 `claude`가 설치·로그인되어 있어야 합니다(터미널에서 `claude`를 한 번 실행해 로그인).
> 화면만 확인하려면 모의 엔진으로 켭니다: `CARDNEWS_ENGINE=mock .venv/bin/python -m app.main` — 이때 화면 상단에 "모의 데이터입니다"가 표시됩니다.
> 이미지는 **Antigravity CLI(agy)**로 만듭니다. 미리 터미널에서 `agy`를 실행해 Google 계정으로 로그인해 두세요.
> 조사 1회에 약 1분, 심층 조사에 약 1분, 카드 7장 제작에 약 3분이 걸립니다.
> 이미지 없이 흐름만 보려면 `CARDNEWS_IMAGE=mock`을 앞에 붙여 켭니다.

## 실행하기 (처음 해 보는 사람용)

준비물: macOS, Python 3.10 이상. 터미널에서 `python3 --version`을 입력해 버전이 나오면 됩니다.

### 1. 터미널 열기
`⌘ + Space` → `터미널` 입력 → Enter.

### 2. 앱 폴더로 이동
터미널에 아래를 입력하고 Enter. 이후 명령은 모두 **이 폴더에서** 입력합니다.
```bash
cd ~/Documents/Aifel/card-news-workflow-kit
```
폴더를 다른 곳에 두었다면 그 경로로 바꿉니다. (Finder에서 폴더를 터미널 창으로 끌어다 놓으면 경로가 입력됩니다.)

### 3. 처음 한 번만: 실행 환경 만들기
```bash
python3 -m venv .venv
```
```bash
.venv/bin/pip install fastapi uvicorn pillow
```
두 번째 실행부터는 이 단계를 건너뜁니다.

### 4. 앱 켜기
```bash
.venv/bin/python -m app.main
```
아래처럼 나오면 켜진 것입니다. **이 터미널 창은 닫지 말고 그대로 둡니다.**
```
열기: http://127.0.0.1:8765
INFO:     Uvicorn running on http://127.0.0.1:8765 (Press CTRL+C to quit)
```
`포트 8765가 사용 중입니다`가 나오면 이미 켜져 있거나 다른 프로그램이 쓰는 중입니다. 다른 번호로 켭니다.
```bash
.venv/bin/python -m app.main 8766
```
이때 아래 브라우저 주소도 `8766`으로 바꿉니다.

### 5. 브라우저에서 열기
Chrome이나 Safari 주소창에 입력합니다.
```
http://127.0.0.1:8765
```
1. 주제(예: `AI 최신소식`)를 입력하고 **조사 시작**
2. 후보 1~3개를 체크하고 **다음 단계**
3. 질문에 답하고 **답변 제출** → 편집 판단과 스토리보드가 보입니다

주소 끝의 `#p_...`가 프로젝트 번호입니다. 새로고침하거나 이 주소를 다시 열어도 진행 상태가 그대로 남습니다. 새 주제는 왼쪽 위 **카드뉴스 에이전트**를 누릅니다.

### 6. 앱 끄기
앱을 켠 터미널 창을 클릭하고 `Control + C`를 누릅니다. 입력 대기 줄(`%`)이 다시 보이면 꺼진 것입니다.

터미널 창을 이미 닫아 버렸다면 새 터미널에서:
```bash
pkill -f app.main
```

### 기록 지우기
진행한 프로젝트는 `data/` 폴더에 저장됩니다. 앱을 끈 뒤 `data` 폴더를 휴지통으로 옮기면 처음 상태가 됩니다.

## 확인한 것 (모의 엔진, 2026-10-23)
- 새로고침 후 후보·현재 질문 유지
- 답변 동시 2회 제출 → 답변 1건, 작업 1건만 생성 / 지난 질문 답변은 `stale_question`으로 거절
- 같은 requestId 재요청 → 같은 runId, 다른 입력 → `request_conflict`
- 작업 취소 → `cancelled` 표시와 재시도 버튼
- 작업 중 서버 종료 후 재시작 → `interrupted` 표시, 재시도로 복구

| 검색 실패 표시 | 통과 | 검색 도구를 뺀 테스트 서버에서 "검색 실패 — 이유 + 다음 행동 + 재시도" 표시. 기억으로 후보를 만들지 않음 |
| 로그인 필요 표시 | 미확인 | 로그아웃 상태를 만들지 않음. 코드상 `auth_required`로 분류 |
| 실제 엔진 실행 중 취소 | 미확인 | 하위 프로세스 그룹 종료 코드는 있으나 실제 실행 중 취소는 시험하지 않음 |

알려진 한계: 이 확인 실행에서는 선택지 값이 영어(general/developer)로 나왔다. 지시문에서 한국어로 고쳤지만 고친 뒤 다시 실행해 확인하지는 않았다.

엔진 원본 응답은 `data/projects/<id>/logs/`에 저장됩니다.

- **밝은 배경 그림:** 그림 배경이 밝으면 위쪽 어두운 제목 영역과의 경계가 회색 띠처럼 보입니다. 대비 점검은 통과합니다.
