# 제출: 나만의 워크플로로 확장하기 — 여행 구상 도우미

카드뉴스 에이전트의 흐름(조사 → 후보 비교 → 사람이 선택 → 결과물 → 검수)을 **여행지 구상**에 적용했다.
여행 구상을 한두 문장으로 적으면 실제 자료로 핵심 개념을 제안하고, 고른 개념마다 따져볼 쟁점과 근거가 있는 해설을 그림 카드로 만든다. 자료가 모자란 곳은 '자료 부족'으로 표시한다.

**실행 결과 보기 링크: https://borigunbbang.github.io/travel-idea-helper/** (정상 입력의 카드 12장과 해설 문서, GitHub Pages 정적 페이지)

`data/`는 git에서 빠지는 폴더라, 제출에 필요한 화면·산출물·엔진 기록은 이 `submission/` 폴더로 복사했다. 화면은 `shoot.sh`(크롬 헤드리스)로 실제 앱을 찍었다.

## 1. 실행 증거 — 정상 입력 (실제 엔진: Claude CLI sonnet, 2026-10-23 조사, 10-26 최종 승인)

| 단계 | 누가 | 내용 |
|---|---|---|
| 입력 | 사람 | `2박 3일 혼자여행, 국내 여행, 예산 50만원 이하, 힐링` |
| 조건 가리기 | AI | 정해진 조건 5개(기간·동행·범위·예산·분위기). 정하지 않은 조건 6개(출발 시기, 출발지, 이동 수단, 예산에 교통비 포함 여부, 좋아하는 것, 숙소 취향)를 '정하지 않음'으로 표시 |
| 핵심 개념 제안 | AI + 웹 검색 | 6개: 산림치유 2박 / 템플스테이 / 온천 휴식 / 강원 바다·숲·메밀밭 / 섬·해안 걷기길 / 한옥 도시 걷기. 개념마다 후보 지역·출처·부족한 자료 |
| 개념 고르기 | 사람 | '가을 끝자락 강원 바다·숲·메밀밭 느리게 돌기', '한옥 도시를 천천히 걷는 조용한 도시 휴식' |
| 질문 | AI → 사람 | "어디에서 출발하고, 어떻게 이동할 계획이야?" → **서울·수도권, 대중교통**(기간·예산은 이미 적어서 묻지 않음) |
| 해설 | AI + 웹 검색 | 쟁점 7개. 근거 충분 0 · 근거 일부 3 · 자료 부족 4. 예: "혼자 예산 50만원 안에 들어오나?" → 자료 부족 |
| 카드 | 앱 | 12장(표지·한눈에 보기·개념 2·쟁점 7·아직 확인 못 한 것) |
| 최종 승인 | 사람 | 승인 버전 v11. 근거가 모자란 쟁점 7개를 알고 승인 |
| 내보낸 파일 점검 | 앱 | **통과 43 · 실패 0 · 미확인 6**. 미확인: 링크 2개 자동 접속 차단, 게시일 미확인 출처가 있는 쟁점 3개, 휴대폰 실제 보기 |

- 화면: `screens/a1-review-cards.png`(카드 보기), `a2-photos.png`(후보 사진 한눈에 보기), `a3-concept-detail.png`(자세히 보기와 쟁점 목록), `a4-mobile-cards.png`(휴대폰 폭), `a5-approved-downloads.png`(승인 후 내려받기·점검)
- 산출물: `run-normal/export/` — 카드 PNG 12장, `travel-cards.zip`, `guide.html`·`guide.md`, `sources.json`, `check_report.md`
- 엔진 원본 응답: `run-normal/engine-logs/`(조사·해설·답변 각 1회), 사진 기록 `run-normal/photos.json`

## 2. 실행 증거 — 자료 부족 입력 (실제 엔진, 2026-10-26)

입력: `다음 달쯤 어디든 조용한 데 가고 싶다` — 시기 말고는 장소·기간·동행·예산·출발지가 없는 모호한 요청.

| 확인할 것 | 결과 |
|---|---|
| 없는 조건을 지어내지 않는가 | 시기만 '2026년 11월쯤'으로 해석하고, **8개 조건을 '정하지 않음'**으로 표시(기간, 동행, 예산, 출발지, 이동 수단, 국내/해외, 좋아하는 것, 숙소 취향) |
| 개념에 부족한 자료가 보이는가 | 개념 7개 모두에 부족한 자료 2개씩. 7개 중 6개는 출처가 1개뿐 |
| 꼭 필요한 것만 묻는가 | 고른 개념(섬에서 하룻밤, 해미읍성 산책)에 대해 **"어디에서 출발하시나요?"**만 물음. 이유: "시기(11월쯤)는 정해져 있어서 따로 묻지 않는다" → 답: 서울·수도권(시험자가 다른 구상과 같은 출발지로 답함) |
| 그럴듯하게 채우지 않는가 | 요약에 "1박 2일로 가정하고(기간·동행·예산은 정하지 않아 가정)"라고 밝힘. 쟁점 6개 중 4개가 '판단 보류'. 근거 일부 2 · 자료 부족 4. 출처끼리 다른 개방 시간은 "전화로 확인해야 한다"고 적음 |
| 입력 보완·재실행으로 이어지는가 | 출처가 0개인 6번 쟁점("서울에서 해미읍성까지 대중교통으로 1박 2일이 편한가?")에 **'이 쟁점 자료 더 찾기'** → 출처 0 → 2(서울남부→서산·해미 버스 시간표), 자료 부족 → 근거 일부. 여전히 '판단 보류'와 다음에 부족한 것(정류소→읍성 교통, 숙소)을 남김. **다른 쟁점 5개는 그대로**(v1) |

- 화면: `screens/b1-select-gallery.png`(사진 모음으로 개념 고르기), `b2-select-detail.png`(고르기 단계의 자세히 보기), `b3-question.png`(질문), `b4-review-cards.png`(해설 카드), `b5-issue6-before-after.png`(자료 더 찾기 전후 카드)
- 기록: `run-poor/project-before-more.json`, `project-after-more.json`(전후 프로젝트 상태 전체), 카드 PNG 11장, `engine-logs/`
- 이 구상은 시험용이라 최종 승인하지 않았다(해설 검토 단계).

## 3. 실패와 개선

### 대표 사례: 후보 여행지 사진이 여행지 사진이 아니었다

| 회차 | 방식 | 실제 입력 | 기대 | 나온 결과 | 바꾼 점 |
|---|---|---|---|---|---|
| 1 | 위키백과 문서의 대표 사진 | 정상 입력의 후보 지역 15곳 | 그 지역의 풍경 사진 | 제천 → **위치 지도**, 온양온천 → **1912년 흑백 사진**, 안동 → 시청 건물, 남해 바래길 → 바다 지도 | 지도·로고 파일 거르기(DECISIONS 60), 그래도 대표 사진의 한계가 커서 방식 변경 |
| 2 | 공용에서 '장소 + 풍경' 검색 | 같은 15곳 | 최근 컬러 풍경 | 영주 → **정치인 사진**(이름이 겹침), 온양온천 → **열차**, 올레길 → **표지판**. 풍경 낱말을 필수로 하자 대부분 '찾지 못함' | 검색 대신 장소의 공용 분류를 쓰기로(DECISIONS 61→63) |
| 3 | 장소 문서 → 위키데이터 → **공용 분류**의 최근 사진에서 고름. 인물·탈것·건물·유물 낱말, 옛 연도가 적힌 사진 제외 | 같은 15곳 | 최근 컬러 풍경 | 영주 → 희방사(2017), 경주 → 동궁과 월지(2024), 횡성 → 웰리힐리파크 야경, 안동·제천 → 도시 전경. 시험 중 횡성 → **1951년 비행장 항공사진**(스캔한 날이 촬영일로 적혀 있음)이 걸려 '이름·설명에 옛 연도' 거르기를 추가 | — |

**남은 문제와 다음 수정 방향**
- 온양온천은 장소 분류가 없어 '아산' 도시 분류로 넘어가 **아파트 단지 사진**이 나온다. → 도시 분류로 넘어갈 때는 풍경 낱말을 필수로 하는 방법을 검토
- 위키미디어 요청 제한(429): 시험을 많이 해 정상 입력 15곳 중 7곳만, 자료 부족 입력 11곳 중 3곳만 사진을 받았다(나머지는 '받지 못함' 또는 '찾지 못함'). 요청에 연락처를 넣으면 나아질 수 있지만 사용자가 원하지 않아 넣지 않았고, 시간이 지난 뒤 '못 받은 사진 다시 찾기'로 다시 받는다.
- 시험 도중 요청 하나가 46분 멈춘 일이 있어 장소당 60초 강제 제한을 넣었다(DECISIONS 59).

### 그 밖에 기대와 달랐던 것

| 사례 | 바꾼 점 / 결과 |
|---|---|
| AI가 근거를 '충분'이라고 했지만 출처가 하나뿐 | 앱이 실제 출처로 상한을 정해 '일부'로 낮추고 이유를 표시(DECISIONS 47). **낮추는 동작은 모의 시험에서만 확인**했다. 실제 실행 두 번(쟁점 13개)에서는 AI가 스스로 '일부'·'부족'으로 매겨 낮출 일이 없었고, 앱은 '(앱 점검)' 부족한 자료(출처 1개뿐, 공식 자료 없음, 게시일 미확인)만 더했다 |
| 카드 표지의 긴 조건이 16자에서 말없이 잘림("예산 50만원 이하 (교통비") | '…'로 끝나게 하고, 그리는 방식이 바뀌면 카드를 자동으로 다시 그리게 함 |
| 휴대폰 폭(375px)에서 카드 보기 화면이 옆으로 넘침 | 작은 카드 줄이 칸을 늘리던 문제를 고쳐 넘침 없음 확인(`a4-mobile-cards.png`) |
| 자료 부족 입력 6번 쟁점: 출처가 0개인데 판단에 "차로 2시간 이내라는 설명"이 들어감 | 앱 점검이 '자료 부족'으로 표시해 숨기지 않았고, '자료 더 찾기'로 실제 시간표 근거를 붙임(위 2). 남은 문제: 출처 없는 문장 자체를 막지는 못함 → 출처 없는 쟁점의 판단 문장에 경고를 붙이는 방안 |
| 자료 부족 입력: '국내만 볼지 해외도 볼지'를 정하지 않음으로 표시해 놓고 개념 7개를 모두 국내로 제안 | 숨은 가정. → 다음 수정: 개념 제안에도 가정(예: '국내로 가정')을 화면에 밝히게 지시문 보강 |
| 정상 입력의 질문이 반말("…계획이야?") | 지시문에 말투 규칙이 없음 → 다음 수정: 질문 말투 지정 |
| 질문 화면의 직접 입력 칸 예시가 질문과 상관없이 늘 '예: 1월 둘째 주'(출발지 질문에도 그대로, `b3-question.png`) | 예시를 '선택지에 없으면 직접 적어 주세요'로 고침(캡처는 고치기 전 화면) |
| 대중교통(버스) 쟁점 카드에 비행기 아이콘 | 쟁점 종류 '이동'이 아이콘 하나를 씀 → 다음 수정: 버스·기차·배 낱말로 아이콘 나누기 |

## 4. 카드뉴스 실습 완료 범위 (확장 전)

- **완료:** 실제 엔진으로 "ai 최신 뉴스" 카드뉴스 한 편을 조사 → 후보 선택 → 독자 질문 → 스토리보드 승인 → 카드 7장 제작 → 카드별 수정 → **최종 승인**하고 내려받음. 결과물: `cardnews-done/result/`(카드 PNG 7장, `sources.md`, `image_credits.json`)
- **당시 확인 기록:** `cardnews-done/README-cardnews.md`(확인 결과 표 전체), `ACCEPTANCE-cardnews.md`. 코드는 git 커밋 `725cf53`
- **카드뉴스에서 남았던 것:** 5번 본문 "세부 구조는 몇 달 안에 공개하겠다고 했다"가 카드 출처(Al Jazeera, ABC)에 없음 — 사람이 직접 확인할 항목으로 남김. agy 이미지 쿼터 초과로 그림은 Claude CLI 도형 대체 그림. 미확인: 로그인 필요 표시, 실행 중 취소, 이미지 실패 재시도(실제)

## 5. 아직 확인하지 못한 것 (여행 구상 버전)

- 로그인 필요 표시, 실제 엔진 실행 중 취소, 작업 중 서버를 다시 켠 뒤 복구 — 코드 경로는 카드뉴스 때와 같지만 여행 버전으로는 다시 시험하지 않음(미확인)
- 카드를 실제 휴대폰으로 넘겨 보기(점검 보고서에도 '미확인')
- 출처 링크 2개는 자동 접속이 막혀 열림 여부 미확인, 게시일을 모르는 출처가 많아 날짜 점검 대부분 미확인
